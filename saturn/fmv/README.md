# Saturn FMV package status

The Saturn FMV workflow has not been ported into the current build. This
directory is a placeholder, and the FMV subtitle screenshot in `saturn/docs/`
is reference material from the mature translation rather than a generated
artifact.

A future implementation needs its own verified source-media contract,
subtitle authoring model, timing and encoding rules, generated outputs, tests,
and build/install steps. The current default profile does not inspect or modify
FMV streams.
